# F17, step 5 of 5: the handoff

## What a reader gets

Every completed answer of the six operations the profile names says what
it stands on: the digest of this tool and of the language it reads, and
the compiler, the encoding, the solver and the runtime behind it, each
either a version or the reason there is none. An obligation says where
it stands as a statement and what happened to the attempt to settle it,
in two fields whose words share no vocabulary. A failure inside the tool
is answered as a failure of the tool, under a status an answered request
never carries, with no claim, no result and no revision.

## What a reader must know

- `evaluate` keeps the answer it had. It is this tool's own operation,
  named in none of the operation categories of the authority, and an
  accepted test pins its answer to six fields. Whoever wants the block
  there widens that test first, with the owner's word for it. The
  manifest says so under `documentation.stands_on`.
- The field is spelled `stands_on`, not `provenance`: the word carries
  `proven` inside it, and several accepted tests refuse any answer whose
  text says something was proven.

## What was not verified

- That a failure of the tool can be reached through the input of the
  command. It cannot without a defect planted on purpose, so it is
  observed through the public entry point the command calls.
- Anything about the `evaluate` answer.
- That the version named for the compiler is the version of the code that
  answered: it is read from the metadata of the installed package, which
  an install can leave behind a working tree.
- The behaviour under a solver or an encoder: there is none here.
- The craft record of this run still names the prefactor commit by the id
  it had before the branch was moved onto the current main, and reports
  the count measured then. Recording it again refuses, because from the
  baseline this run exported, the history now starts with a commit of
  another delivery. The generated summary carries both the refusal and
  the figures measured on this tree.
